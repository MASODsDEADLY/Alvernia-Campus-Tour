ALVERNIA UNIVERSITY CAMPUS EXPLORER — PROJECT EVIDENCE

1. NAMED AUDIENCE AND CLEAR NEED
Audience: prospective students and first-time visitors to Alvernia University.
Need: provide a simple interactive way to explore selected campus landmarks in 3D and read a short background summary before visiting.

2. WORKING FEATURES
Feature A — Campus-tour UI: campus-focused maroon-and-gold interface, searchable list of six stops, landmark story/coordinate panel, and previous/next controls.
Feature B — Yellow center reticle and coordinate capture: aim the center dot at a visible 3D surface and capture latitude, longitude, and elevation when depth picking succeeds.
Feature C — Guided tour and flight controls: map-pin selection, guided stop cycling, speed/height/heading controls, pause, reset, and camera-follow option.
Feature D — Edge-case UI: “Preview edge case” shows the safe expected response when no 3D surface exists beneath the center dot.

1) PASS — Pause preserves position.
2) PASS — North movement increases latitude.
3) PASS — East movement increases longitude.
4) PASS — Heading wraps in both directions.
5) PASS — Height limits clamp to allowed bounds.
6) PASS — Zero speed keeps position.
7) PASS — One second equals ten 0.1-second steps within the test tolerance.

Edge case investigated: when the center dot points at sky, empty space, or an unloaded/unpickable tile, Cesium may not return a 3D position. 5. README AND KNOWN LIMITATIONS
Run locally: extract the folder, configure a valid token in config.js, run `python -m http.server 8000` from the project directory, and open http://localhost:8000. Internet access and Google Photorealistic 3D Tiles access are required. Do not publish a private token in a public repository; a token shipped to the browser is visible to users.

Known limitations: Plex and Student Center coordinates are unverified estimates; pins are not navigation-grade; tile detail and loading depend on internet/service/hardware; center-point picking can fail if no surface is visible; captured points are not automatically saved; movement is a simplified simulation without aerodynamics, collision detection, or terrain avoidance; history summaries are brief and need independent fact-checking.
